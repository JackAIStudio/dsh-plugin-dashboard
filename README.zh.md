# dsh-plugin-dashboard

> **JackDSH 插件与版本大盘**：在 DSH 设置的「插件」分区提供精细化版本看板、来源分类（由 Jack 维护 / 由社区维护）、实时搜索与无感热开关。

---

## ✨ 核心特性

1. **底座内核与客户端版本透明化**：
   - 自动透传 `@deepseek-ai/dsh` 官方内核底座版本号（如 `v0.1.2-rc.1`）；
   - 展示 JackDSH 客户端发行版版本；
   - 呈现 Node / OS 运行架构。
2. **清晰的来源分类与精准版本**：
   - 三段式科学分类：`全部插件`、`由 Jack 维护`、`由社区维护`；
   - 深入各插件物理目录读取 `package.json` 中的真实声明版本号；
   - 区分 `Jack 维护` 与 `社区维护` 专属徽章。
3. **实时搜索栏**：
   - 支持按名称、包名或描述即打即搜，快速定位目标插件。
4. **零命令行依赖的轻量热开关**：
   - 自动映射 Cordis 内部真实 Entry ID 并改写 `cordis.patch.yml`，不依赖系统安装 Node、pnpm 或全局 `dsh` 命令；
   - 在 JackDSH 一键安装包（小白用户纯净环境）下绝不报错。
5. **0.3 秒无感软重载与确认弹窗（Modal Dialog）**：
   - 切换开关后居中弹出确认重载对话框，点击按钮 0.3 秒完成前端极速刷新生效；
   - 零常驻 SSE / WebSocket 连接占用，不抢占浏览器 6 条 HTTP 并发配额，多会话标签页依然畅快多开。
6. **一键导出系统与插件诊断报告**：
   - 一键复制 Markdown 格式的环境与插件健康度列表，方便直接复制反馈。
7. **全量模型与凭据配置迁移独立板块**：
   - 在设置中提供专属的「配置迁移」独立工作台，一键打包导出私密配置包，新电脑一键导入瞬间满血复活。
8. **JackDSH 版本号无缝融入设置按钮**：
   - 在侧边栏底部的设置按钮上直接内嵌精致版本徽章（如 `v9.14.8`），常态常驻，一眼可知。
